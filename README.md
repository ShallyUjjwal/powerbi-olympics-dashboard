# 🏅 Paris 2024 Olympics Power BI Dashboard

Dive into the world of data analytics with a complete end-to-end project focused on the **Paris 2024 Olympic Games**. This project walks you through building a dynamic and interactive Power BI dashboard using real Olympic data, enriched with **Python scripts**, **Figma design**, and **Power BI's advanced features**.

Ideal for showcasing your **data analytics**, **visualization**, and **storytelling** skills to potential employers, clients, or as a portfolio project.

![Olympic Dashboard Overview](./images/paris_olympics_dashboard.png)

---

## 📦 Project Overview

This project demonstrates how to extract, clean, model, and visualize Olympic Games data using modern analytics tools:

- 🔹 **Python** for data extraction and cleaning  
- 🔹 **Power BI** for interactive dashboarding  
- 🔹 **Figma** for custom UI/UX layout design  
- 🔹 **Kaggle** as the data source

The final dashboard provides an end-to-end view of Olympic performances—medals, countries, athletes, and trends—across different years with dynamic interactivity.

---

## 📊 Dashboard Structure & Features

The Power BI report consists of **4 main pages**, each tailored for specific analytical perspectives:

### 1. 🏠 Overview
- Total medals summary (Gold, Silver, Bronze)
- Gender-based participation analysis
- Highlight of top-performing country
- Interactive world map of medal winners
- Key statistics: number of athletes, countries, and events

### 2. 🌍 Country
- Filterable country list with flag icons
- Medal tally per country with breakdown
- Sports-specific performance view
- Highlights for top countries and medal distribution

### 3. 🧑‍🤝‍🧑 Athletes
- Detailed list of athletes by:
  - Name, Country, Sport, Year, Medal
- Insights into athlete age and gender distribution
- Medal split by gender
- Interactive table and visualizations for quick lookup

### 4. 📈 Historical
- Line and stacked column chart for medal trends over years
- Drill-through capability by year and sport
- Filters for year, country, and sport using a collapsible panel
- Comparative view of countries over time
